# Daniel Jeon — Portfolio

A responsive React + TypeScript portfolio with a warm charcoal, olive, cream, and muted-gold palette. DM Sans is used throughout the entire page, including the hero, section headings, project titles, navigation, and body copy, for a consistent, readable sans-serif look.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL Vite prints in your terminal.

## Add your headshot

The hero is set up to load your actual portrait from:

`public/daniel-headshot.jpg`

Copy your professional headshot into the `public` folder and name it `daniel-headshot.jpg`. The page shows a designed initials placeholder until the image is present. The generated design reference image is not used as your portrait.

## Build for production

```bash
npm run build
npm run preview
```

## Before publishing

- Confirm project descriptions accurately reflect your contributions.
- Replace the Synth Tree GitHub link with the correct repository URL if you want to link directly to it.
- Add your resume PDF if you want a resume button.
- Add your headshot to `public/daniel-headshot.jpg`.
